```text
交付文字型及扫描版 PDF、Word、TXT、Excel 上传资料的解析和有界检索、项目与已接受实验证据读取、联合问答、逐条可打开引用、错误/缺失/冲突提示及刷新后的结果读取。扫描 PDF 需 OCR、原页/区域引用和识别质量提示，支持文字与扫描混合页。资料读完后直接用于问答，无需另点确认。View 成员可以提问；上传、分析执行、确认和发布权限保持。Excel 复用现有工作簿索引，原始单元格可直接引用，但不自动成为已确认实验数据。新的科学计算仍进入现有分析计划审核；不在 v1 添加失败诊断、参数优化、公开文献搜索或自动数据发布。

在已授权的实施范围内，自主完成必要的代码、迁移、API/生成客户端、界面、测试和文档，不在第一版代码或单个里程碑完成后把剩余工作交还用户。每次完成一个连贯里程碑后验证、修复本任务导致的问题、记录证据，再继续。普通实现选择用代码和测试解决；影响产品范围、权限、科学含义或新外部服务的选择先讨论。

工具复用后端领域服务和认证项目范围，保证来源、版本、值、单位、缺失和覆盖信息可追溯；模型不能绕过确认、执行授权或发布事务。沿用当前部署 provider 和实际基线中可用的运行机制；不得因另一工作区的计划存在就自动合并它。保护不属于本任务的修改与历史科学结果。

完成条件：所选范围全部实现；验收文档的确定性必需用例、检索质量和真实 provider 有界评测通过；隔离 PostgreSQL、完整应用浏览器流程及适用回归通过；契约、进度与交付报告一致。明确区分替身、合成资料与真实模型证据；未运行或被跳过的必要验证不得标记通过。

若缺少必要凭据、环境、设计决定或已有授权，先完成不受影响工作，记录具体阻碍、已尝试的证据和恢复条件；按宿主目标工具的规则处理状态。只在用户要求时暂停；预算不足或阶段完成不代表整个目标完成。不得自行启动另一个 Goal、清理无关工作区、恢复其他任务或扩大授权。

提交、推送、合并、部署与真实私有资料的使用以本次启动和后续用户指令的授权为准。目标交付默认是本地实现与审查材料；旧任务的上线授权不能用于本任务。
```

## 交接时应能回答

- 哪个里程碑已经由什么证据完成，下一步是什么？
- 当前 checkout 和基线是什么，哪些既有修改需要保留？
- 哪些产品决定有用户答复，哪些限制仍未解除？
- 最终门槛是否全部通过；若未通过，准确缺哪项证据？

这些信息记录在现有进度/当前里程碑中；不为每次恢复新建平行状态文档。
