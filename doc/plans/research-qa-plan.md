## 目标与阅读入口

用户上传 PDF、Word、TXT 或 Excel 资料后，可以在 Ask LabRat 中结合文件原文、当前项目背景、已确认工作簿证据及已接受实验数据提问。回答中的事实可定位回原文或准确的数据版本，并区分原始资料与已审核实验含义；证据不足、冲突或需要新计算时明确说明。

本计划供 GPT-6 Astra 开发目标使用。Astra 是执行开发任务的模型名称，不代表改变 LabRat 部署时选定的 AI provider。用户于 2026-09-27 启动完整实施目标；当前执行状态见 `doc/current-milestone.md`。真实 provider 评测仅使用合成或另行获准资料。

## 已确认范围

2026-09-27 用户明确选择：

- 首期只交付上传资料与实验数据的带引用问答。
- 文献来源仅限用户上传的文献和项目资料。
- Agent 可自动检索和读取；新的科学计算仍须先审核分析计划。
- 首期支持文字型及扫描版 PDF、Word、TXT 和 Excel，按 `.pdf`、`.docx`/`.doc`、`.txt`、`.xlsx`/`.xls` 验证；扫描 PDF 的 OCR 和原页区域定位是必需能力。
- 资料完成解析/索引后直接用于问答，无需额外点击“确认使用”。
- View 成员可以发起只读问答；其他操作仍受各自权限控制。

失败原因诊断、下一轮实验草案、DoE/贝叶斯优化、公开文献搜索、外部文献库、跨项目知识共享和 MCP 对外接入属于后续方向，不是 v1 的完成条件。本期不把文档中的值自动发布为实验数据，也不自动更新项目背景。

首期产品选择已全部确定，详见设计决策表。解析器、OCR 引擎、检索策略和工程限额已落实到[实现契约](../contracts/research-qa-v1.md)，M0–M5 的最终证据见[验证报告](../qa/research-qa-verification.md)。不必重复询问已确认范围；只有出现新的实质性范围或权限变化时再讨论。

## 推荐实现原则

- 后端领域服务提供能力；模型工具只做窄适配；界面与工具复用同一授权和证据读取实现。
- 一个协调 Agent 使用少量只读工具；其可见工具集中不包含代码执行、确认、数据发布或权限管理。
- 文档陈述、Excel 原始单元格、用户填写的项目背景、已确认区域、已接受实验值分别标明来源类型。原文可以立即引用；尚未确认的实验身份、字段含义或单位不能被自动当作已确认结果。
- 本期提供文献与数据联合问答。需要均值、归一化、拟合或其他新科学结果时，衔接现有分析审核流程。
- 先用代表性语料比较检索效果；索引/模型选择保持可替换，不为使用 Agent 强制引入新平台或第二套队列。
- 按已确认 D6 开放 View 成员的只读问答，单独验证该入口；其他项目权限及审核边界保持。

## 关键体验

有上传权限的用户从已有 Ask LabRat 附件入口添加 PDF、Word、TXT 或 Excel。参考资料显示解析中、可检索、部分可读或失败；完成读取后自动可引用。View 成员可向已上传且可访问的资料提问。Excel 必须走原区域审核；新问答只读取当前已确认的区域或已接受实验数据。

回答中的引用可以打开文件名、版本和精确位置：文字型 PDF 使用页码及文本定位，扫描 PDF 使用原始页码和识别区域高亮，Word 使用段落/标题/表格位置，TXT 使用行号，Excel 使用工作表和单元格/范围。已审核实验引用打开对应快照或确认区域；后台重新检查权限。

回答明确本次使用了哪些资料和实验。证据冲突时并列展示来源；资料不足时说明缺口。涉及新计算时提供进入现有分析审核的动作，用户没有请求计算时不能仅因提问而悄悄新建分析任务。

## 完成与交付

v1 完成需同时满足：已决定范围全部交付、验收清单中的必需行为通过、真实 provider 质量检查通过、既有科学流程没有回归、进度与契约同步。仅模型替身测试通过不代表问答质量已验证。

缺凭据、运行环境或必要的产品决定时，完成不受影响的工作，记录具体缺口与恢复步骤；目标生命周期遵守宿主规则。预算耗尽、代码已写完或部分测试通过均不是整体完成依据。

本开发计划的交付物是本地可验证实现和审查材料。启动指令明确禁止未经后续授权提交、推送、合并、部署及使用真实私有资料，不从旧任务的授权推导。
