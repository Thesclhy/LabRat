Last reviewed: 2026-09-27

关联：[总计划](research-qa-plan.md)、[设计决定](research-qa-decisions.md)、[验收](../qa/research-qa-acceptance.md)。文字型及扫描版 PDF、Word、TXT、Excel、解析后直接使用及 View 问答均已实现。本文件说明设计原则；实际状态、API、字段和限额以[已实现契约](../contracts/research-qa-v1.md)和[验证报告](../qa/research-qa-verification.md)为准。

## 服务、工具与 Agent

领域服务拥有文件存储、解析、检索、实验读取、引用解析和授权。工具适配器将这些服务包装为明确的输入/输出。一个问答 Agent 根据问题补充证据并生成回答；服务仍可被普通 UI 和测试直接调用。

工具列表按当前用户权限和任务生成，后端在每次调用时再次校验。用户/项目范围由认证会话注入；模型传入的 ID 只能用于选择已授权资源，不能改变授权范围。缓存键必须包含项目、资源版本和适用权限，不能先检索全租户再在回答末尾过滤。

已确认 View 成员可以发起只读问答。为此提供受限问答操作/入口及其运行记录、答案保存；不能把既有同时支持上传/分析动作的入口整体降为 read。View 用户的问题若要求新计算，提示需由有相应权限的成员进入既有审核流程，不借问答授权起草或执行受限动作。

不要求引入 MCP、独立 Agent 服务或多个子 Agent。未来可以在同一领域服务上增加 MCP 适配器。

## 已实现的工具集

以下七个工具已实现于后端，确切参数见 `backend/src/research/evidenceTools.js`。工具返回有界结构化证据；搜索片段与精读内容有不同的覆盖范围标记。

| 工具 | 典型输入 | 返回与边界 |
| --- | --- | --- |
| `get_project_context` | 所需背景字段 | 已保存的目标/材料/方法等、更新时间及内容版本；不自动吸收上传资料成为事实 |
| `search_project_documents` | 查询、分页游标 | 当前文档或工作簿来源、版本、片段/范围、确认区域、已接受字段名及覆盖情况；固定上限；排除失败/不可读/归档部分，搜索摘要不作为引用 |
| `read_document_passage` | 文档版本、片段/位置、有界相邻上下文 | 精确原文、章节上下文、可校验引用定位；不跟随文中链接访问外网 |
| `read_workbook_source` | SourceDocument、工作表、有界范围 | 原始值、显示值、公式文本及已有缓存值、坐标与警告；标明原文证据，不推断已确认实验含义，不执行公式或宏 |
| `find_experiments` | 明确名称/别名或有界筛选 | 项目内匹配身份、候选与活动快照引用；无匹配/多匹配明确返回，不取其他实验补位 |
| `read_experiment_evidence` | 已解析身份、字段、快照引用、有界序列窗口 | 值、类型、单位、百分比尺度、来源、缺失状态、冻结的 snapshot/head；不推断单位或计算新指标 |
| `read_confirmed_region_evidence` | 区域、准确解释版本、范围 | 当前确认区域中的有界单元格及语义；不扩大到未确认区域，不把样本当作整个工作簿 |

问答可读取已有、获准且已接受的分析/图表证据时，复用对应服务并携带结果版本；不默认扩展为检索全部历史运行或未接受结果。是否把该读取独立为工具由真实场景决定。

新均值、比率、归一化、拟合、检验和单位换算进入现有分析审核。普通字段读取、同类型同单位字段筛选/排序和已有项目数量元数据属于查询；不得借“只读”之名绕过新科学计算的审核。

## 新增证据对象的职责

以下是职责模型；持久化表、版本化迁移和 HTTP API 已落实在 v1 契约中。

| 对象 | 责任 |
| --- | --- |
| ContextDocument / DocumentVersion | 指向现有 FileObject；记录项目、类型、不可变内容哈希、解析器版本、可用状态、覆盖缺口和生命周期 |
| DocumentPassage | 保存可重建的分段内容和文档内定位；重建搜索索引不会改变原文件版本或历史引用 |
| EvidenceRef | 用可辨别类型表达文档段落、Excel 原始范围、项目背景、确认区域、快照字段/序列或已有接受结果 |
| AnswerArtifact | 绑定 AgentRun/request，保存最终回答、逐条引用、证据版本清单、可见限制及有限调用统计；生成回答不代表科学确认 |

PDF/Word/TXT 使用文档解析适配器；Excel 复用现有 FileObject/SourceDocument、索引和范围读取，不新建重复的工作簿存储或发布链路。统一资料目录可以引用这些不同资源；搜索文本不得代替单元格坐标和原始值。新文档证据也不能直接伪装为可发布的工作簿区域。

Excel 原始引用使用独立类型 `workbook_raw`，并携带未确认状态。尚未确认的原文不能被作为已确认实验值或审核分析的合法输入；只有既有审核服务能建立对应资格。原始文件与后续接受结果有差异时并列说明来源与版本，不静默选择或覆盖。现有 AI/科学契约已明确这个问答读取扩展，保持计算和发布不变量；确认区域和接受快照使用各自独立的证据类型。

项目背景当前可变，回答需保存本次所用字段内容的版本/哈希及合法定位，避免以后编辑背景后旧答案显示新的依据。项目背景与历史对话也必须保留“用户陈述”身份；聊天中的未验证断言不能自动升级为实验事实。

## 引用的最小契约

- 文档引用：文档与版本 ID、文件内容哈希、片段 ID、定位、必要的原文摘录和解析覆盖情况。
- PDF 定位：准确页码与可验证文本范围；扫描内容额外保留原页坐标区域、OCR 文本及处理版本；Word 定位：原文件版本下的稳定段落/标题路径或表格行列（必要转换保留映射）；TXT 定位：行号/字符范围；Excel 原文定位：SourceDocument/index 版本、工作表及精确单元格/范围。
- 实验引用：experimentId、dataSnapshotId、recordIndex、字段/序列标识、来源单元格/范围、值与单位；确认区域引用准确 revision ID。
- 回答片段引用其实际支持的证据 ID。单独列一组文件名不足以通过验收。
- 后端只接受本次运行真正读取且当前仍有权限的来源；检查版本、定位、摘录和引用关联。跨项目、未读取或伪造引用不得静默通过。
- 对结构化数值引用精确校验值、单位及尺度。引用确实存在，不代表自由文本解释必然正确；含义是否受证据支持还须质量评测。
- 回答中的事实、资料之间的冲突、证据覆盖不足分别表达。本期不生成实验失败机制诊断或下一轮参数建议。

资料重新上传生成新版本；重解析保留解析版本和定位兼容信息。归档资料退出新的检索，但已有合法历史引用保留其来源身份；失去权限时禁止返回其片段。原文不可用时显示不可用原因，不能用新版同名文件替换旧依据。

## 文档接入与安全边界

上传复用现有项目文件权限；索引状态区分等待、解析中、可用/部分可用、失败及归档。已确认 D5：解析完成后自动可检索，不增加“等待用户确认纳入”状态。文件哈希用于去重识别，同名不同内容不能覆盖历史。

解析前检查声明类型和实际类型、资源上限与可支持格式。覆盖 `.pdf`、`.docx`/`.doc`、`.txt`、`.xlsx`/`.xls`；TXT 测试常见中英文编码并显式处理无法可靠解码的内容。损坏、加密或无法定位的内容明确失败或标记缺口；扫描 PDF 是必需支持格式，不能统一以“无文本层”拒绝。Word/Excel 的宏、嵌入对象、外部链接和公式不执行；公式仅引用文件已有的文本/缓存，缓存缺失不能自行求值。文档显示采用安全渲染。

### 扫描 PDF 的读取与引用

- 逐页判断文本层质量并选择读取或 OCR，支持文字/扫描混合文件；同一内容不得因已有隐藏文字层而重复出现。
- 保存不可变原 PDF、页码、渲染/旋转变换、OCR 引擎/版本/语言配置、文本块及其对应原页区域。引用可打开原页并高亮该区域；重新 OCR 不能改变旧答案使用的处理版本。
- 用清晰中英文扫描、多栏、旋转/倾斜及混合页验证读取顺序和引用。识别结果必须区分可读内容与覆盖缺口；引擎若无可信质量分，不生成虚假的精确置信度。
- 对模糊数字、正负号、小数点、上下标、单位及不可可靠重建的表格保留不确定性；影响答案的内容不能作为确定值输出，可提示用户查看原页或提供清晰版本。
- 识别文字/图注并不等同于理解图片中的科学现象或从曲线提取数值。本期不自动重建图中数据或填补公式。
- OCR 作为文档接入步骤，使用项目权限、页级资源上限和有界任务状态。按原文件哈希及处理版本复用已完成结果，失败只重试必要页面；不让问答工具循环重复 OCR 全文。

文档、历史对话及工具返回文本是待分析资料，不能成为工具授权或系统指令。不会因为论文中的指示改变项目范围、访问网络、发送资料或调用写工具。

已实现有界词法检索、关键词/编号匹配和相邻片段读取，并用固定语料验证。检索方式可以替换，但本期未引入向量服务或外部重排。新增外部 embedding/OCR 服务涉及数据外发和部署配置时，先作为设计变更讨论。

## 问答与分析衔接

问答运行在概念上经历：登记问题与身份 → 选择并读取证据 → 生成与验证回答 → 保存回答或明确缺口。最终状态应能区分成功回答、证据不足、需要审核分析、失败和取消；具体枚举适配现有 AgentRun 契约。

模型选择工具不能绕过现有命令优先级、工作簿区域审核、图表说明或分析入口。明确请求新计算时复用已有方案起草；普通问答发现需要计算时先说明，并提供可由用户触发的分析入口。读取资料本身不得创建 AnalysisRun、ChartSpec 或 DataSnapshot。

保存稳定的请求身份并验证相同身份对应相同输入；重发返回既有状态/答案或明确冲突。发生未知 provider 结局时保留状态并有界恢复，不能宣称请求幂等即可实现模型调用/计费 exactly-once。

页面刷新可重新获取状态及已完成回答。项目/账户切换、请求取消或权限撤销后，迟到响应不得进入另一个会话。服务中断时至少能识别未完成运行并安全重试；只有选定基线确实有持久化恢复能力时，才承诺后台自动继续。

## 资源限制与可观测性

单文件上限、解析资源上限、检索候选/返回片段上限、工具循环轮数、总 provider 请求/令牌预算、期限与并发限制已冻结并实现，具体值见实现契约。所有修复和重试计入同一问题预算；不能多层各自重试导致无界调用。

达到限制返回已完成部分及缺口，不能伪装为完整调查。搜索/读取结果包含分页与完整性标记，避免第一批实验或前几页文献被当成全部证据。

记录可见工具步骤、证据引用、模型/版本、token、已知费用、延迟和安全错误分类；不保存隐藏推理、凭据或无关项目上下文。未知费用不能填成零。沿用部署选择的 provider，不自动切换到其他供应商。
